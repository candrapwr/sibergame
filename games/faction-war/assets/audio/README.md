# Faction War sound effects

Each troop has one spawn sound and one attack sound. Red and Blue share the same sounds.

| Troop | Spawn | Attack | Source |
| --- | --- | --- | --- |
| Knight | `knight-spawn.wav` | `knight-attack.wav` | [Fantasy Weapons and Apparel SFX Library](https://lpc.opengameart.org/content/fantasy-weapons-and-apparel-sfx-library) (`knife-unsheathe-01.wav`) and [Swishes Sound Pack](https://opengameart.org/content/swishes-sound-pack) (`swish-7.wav`) by artisticdude |
| Mage | `mage-spawn.wav` | `mage-attack.ogg` | [Teleport Spell](https://lpc.opengameart.org/content/teleport-spell) by Ogrebane and [Magic Spell SFX](https://opengameart.org/content/magic-spell-sfx) (`magical_4.ogg`) by JaggedStone |
| Beast | `beast-spawn.ogg` | `beast-attack.ogg` | [Monster snarls](https://opengameart.org/content/monster-snarls) by Darsycho (`monster-snarls-2.ogg`, `monster-snarl-attack.ogg`) |
| Boss | `boss-spawn.ogg` | `boss-attack.ogg` | [Monster snarls](https://opengameart.org/content/monster-snarls) by Darsycho (`monster-snarls.ogg`, `monster-snarl-5.ogg`) |

All selected source pages list the assets as CC0. The game serves WAV and OGG files directly; no conversion is needed. If a sound file is missing, that sound is skipped.

Round completion plays `finish.wav`, supplied in this project. The sound toggle and volume setting also apply to it.

The optional looping background track is `bg1.mp3`. Its enable switch and volume are configured separately from sound effects.
